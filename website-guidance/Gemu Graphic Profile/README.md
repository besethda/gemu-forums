# Gemu website graphic profile

Open **Gemu Graphic Profile.html** in a normal browser. It is one self-contained HTML file with embedded images and Inter, so the visual profile works offline. External source links need internet access.

The proposal combines the selected dark construction grid with the warm beige colours from Gemu’s market presentation. It shows palette values, typography, logo treatments, imagery references, Home/Community/Assets examples, components, validation states and developer tokens. Use the Construction/Solid comparison and the three page tabs. Hex buttons copy colours. CSS controls export or copy the reusable foundation. The sample access form demonstrates styling and confirmation only; nothing is sent or stored.

## Files for developers

- `gemu-tokens.css`: proposed foundation, including the local Inter font declaration.
- `design-tokens.json`: values with source/proposal labels.
- `sources/`: original selected reference, intact PDF-rendered logo extracts, unmodified presentation image extracts, existing AI concept images, Inter and its license.
- `AI Image Prompts.md`: original prompts for the three reused wireframe concept images.
- `Graphic Profile Preview.png`, `Graphic Profile Mobile.png`, `Graphic Profile Full.png`: browser previews.
- `source-evidence.json`: compact evidence map and source URLs.

Copy the CSS together with its `sources/Inter-variable.ttf` dependency if using it outside this folder. The HTML embeds that font directly. The font is from the official Google Fonts repository, under the included SIL Open Font License: https://github.com/google/fonts/tree/main/ofl/inter.

## Status and limits

This is a **proposed website graphic profile**, not an approved Gemu brand manual. Added web surfaces, spacing, utility typography, component rules and functional colours are marked as recommendations. No new saturated brand accent is introduced.

The three detailed voxel images are visual references embedded in the supplied presentation. The presentation alone does not establish their engine provenance, authorship or public-use permission. Preserve the source art/signatures, establish attribution and get authorised imagery before using them as public product proof. The cabin/world/robot examples are reused AI illustrations from wireframe v3 and remain labelled concepts.

Existing wireframe and sitemap source files remain unchanged. No website, Drive files, forms, accounts, CRM, Discord bot, applications or marketplace listings were modified. Nothing was publicly deployed or shared with the team.

Browser checks covered loaded fonts/images, desktop/mobile fit, logo comparison, page tabs and arrow-key navigation, hex copying, CSS download, required form fields and confirmation/reset. Text contrast was calculated for the main pairs and supporting/functional colours; dark and light control boundaries exceed 3:1. This is implementation review, not user research or a complete accessibility certification.
